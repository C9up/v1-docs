# Nebula — the component set

`@c9up/nebula` ports the shadcn/ui set onto [Aurora](/en/modules/aurora), organised as atomic design: seventy-five components across four layers, plus the headless behaviour layer Radix would otherwise provide.

Its documentation has its own section: **[Nebula](/en/nebula/)** — installation, owning the source, composition and reactivity, languages and direction, and one page per component.
